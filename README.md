# thesis-docx-merger (docx-template-merger)

A QW/AI-agent **skill** that merges plain-text chapter files, CSV tables and images into a properly sectioned Word thesis (`.docx`) following a university template's section structure — no manual copy-pasting, no LibreOffice required.

Turn Markdown-ish `.txt` sources into a submission-ready thesis: per-chapter sections with automatic headers, LaTeX math converted to native Word (OMML) equations, three-line (booktabs-style) tables, superscript citations that link to their reference entries, and an auto-refreshing table of contents.

## Features

- **Template-aware sectioning** — parses every `sectPr` of the template (摘要 / Abstract / 目录 / 结论 / 参考文献 / 致谢) and overwrites placeholder sections in place; new chapters each get their own section cloned from the body section, so page headers, rules and docGrid match the template byte-for-byte
- **Native Word equations** — `$$...$$` block and `$...$` inline LaTeX are converted to OMML via pandoc (works inside table cells too)
- **Three-line tables** — markdown tables and mounted CSVs get 1.5 pt top/bottom rules, 0.75 pt header rule, no vertical lines, centered on the page
- **CSV table mounting** — `--tables "表1-1=path.csv|English caption"` inserts a table under its caption line, producing *Chinese caption → English caption → table*
- **Live citations** — `[1]`, `[1-3]`, `[5][6]` in body text become superscripted `HYPERLINK` fields jumping to bookmarks (`_Ref{n}`) generated by the reference list (WPS & Word compatible)
- **Reference formatting** — `[n] ...` lines are typeset per template spec (12 pt, 1.25 line spacing, hanging indent by number width)
- **Appendix handling** — auto writes the `附  录` H1 (kept in TOC) and demotes inner headings out of the TOC via `outlineLvl=9`
- **Caption lines** (`表X-X` / `Table X-X` / `图X-X` / `Fig.X-X`) are centered without first-line indent
- **Fonts** — body runs get `Times New Roman` (ascii/hAnsi) + `宋体` (eastAsia); headings keep template fonts
- **Fields refresh** — `updateFields` is set so Word prompts to rebuild TOC and page numbers on open

## Requirements

- Python 3 with [`python-docx`](https://pypi.org/project/python-docx/)
- [pandoc](https://pandoc.org) on `PATH` (for LaTeX → OMML; degrades to raw text if absent)

## Install as a skill

Clone (or copy) this folder into your agent's skills directory so that `SKILL.md` sits at `<skills>/docx-template-merger/SKILL.md`:

```bash
git clone https://github.com/Yao2028908/thesis-docx-merger ~/.qwenworkcn/skills/docx-template-merger
```

## Usage

```bash
python scripts/merge_to_docx.py \
  --template "templates/论文模板（带封面封底）.docx" \
  --output thesis.docx \
  --abstract 00_摘要.txt \
  --conclusion 07_结论.txt \
  --references 08_参考文献.txt \
  --appendix 09_附录.txt:1 \
  --tables "表1-1=tables/表1-1.csv,表2-1=tables/表2-1.csv" \
  02_第1章.txt 03_第2章.txt 04_第3章.txt
```

| Flag | Meaning |
|---|---|
| `--template` | Word template with the target section structure (required) |
| `--output` | Output `.docx` path (required) |
| `--abstract` / `--abstract-en` / `--conclusion` / `--references` / `--acknowledgement` | Files replacing the corresponding placeholder sections |
| `--appendix FILE[,FILE...][:N]` | Appendix files after 参考文献; `:N` demotes headings N levels |
| `--tables "KEY=path.csv\|EN caption"` | CSV mounts inserted under caption `KEY` (repeatable / comma-separated) |
| positional files | Body chapters, one text file per chapter; csv/images following it attach to that chapter |
| `--img-width` | Image width in cm (default 14.5) |

### Supported inputs

| Type | Extensions | Behavior |
|---|---|---|
| Text | `.txt` `.md` `.markdown` | Headings (`#`, `1.1`, `1.1.1`, `1.1.1.1`), math, images, markdown tables, bold, captions, citations, `//` comments |
| Tables | `.csv` | Three-line table (header bold) |
| Images | `.png` `.jpg` `.jpeg` `.gif` `.bmp` `.webp` `.tiff` | Centered, auto `图N` caption from filename |

## Notes

- Third/fourth-level headings (`x.y.z`, `x.y.z.w`) are emitted with 1.25× line spacing, 段前 205 twips, 段后 0.
- Body paragraphs default to 20 pt exact line spacing to match the template; convert to another spec post-generation if your school requires it.
- The included template is for a Master's thesis in Architecture (Beijing University of Civil Engineering style); the script itself is template-agnostic as long as the section/header structure exists.
